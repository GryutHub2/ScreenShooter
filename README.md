# スクショ

範囲を選んで画面を撮り、そのまま赤枠・矢印・赤文字・ぼかしを書き込んで、
コピーか保存をするツール。ScreenPresso の置き換えとして自分用に作ったもの。

タスクトレイ（画面右下）に常駐し、ショートカットキーで呼び出す。

**画像つきの手順書（やりたいこと別）は [docs/manual.md](docs/manual.md)。** このファイルは機能ごとの詳しい説明。

## 起動

デスクトップの **スクショ** をダブルクリックする。タスクトレイに赤いアイコンが出れば動いている。

ショートカットが無いときは、プロジェクトフォルダで次を実行すると作られる（デスクトップとスタートメニューの2か所）。

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-shortcut.ps1
```

Windows を起動したら自動で常駐させたい場合は、**自分でショートカットをスタートアップ フォルダに置く**。
アプリ側には自動起動の設定は無く、置いたショートカットに触れることもない。

1. エクスプローラーのアドレス欄に `shell:startup` と入れて、スタートアップ フォルダを開く
2. プロジェクトフォルダの `スクショ.lnk` をそこへコピーする

`スクショ.lnk` が無いときは `tools\make-shortcut.ps1` で作れる（デスクトップとスタートメニューにできるので、
どちらかをコピーする）。やめたいときは、置いたショートカットを消すだけでよい。

## 撮る

| 操作 | 動作 |
|---|---|
| **Ctrl+Shift+S** | 範囲を選んで撮る（キーは設定で変更できる） |
| トレイアイコンを**右クリック** →「範囲を選んで撮る」 | 同上 |
| トレイアイコンを**右クリック** →「前回と同じ範囲で撮る」 | 前に範囲で撮った所を、選び直さずにすぐ撮る（下の節を参照） |
| トレイアイコンを**右クリック** →「画面全体を撮る」 | いまマウスがある画面をまるごと撮る |
| トレイアイコンを**右クリック** →「録画する（GIF・動画）」 | 範囲を選んで録画する |
| トレイアイコンを**左クリック** | 履歴パネルを開く（出ているときは、もう一度押すと閉じる） |

範囲選択中の操作：

- **マウスを乗せた窓に青い枠が吸い付く。そのまま「クリック」だけできれいに撮れる**（下の節を参照）
- **ドラッグ**して離すと、その範囲を撮って編集画面が開く
- **Space** で、その画面をまるごと撮る
- **Esc** または**右クリック**でやめる
- カーソルの横に拡大鏡が出る。数字は撮ったときの実際のピクセル数

### ウィンドウに吸い付く

カーソルの下にあるウィンドウを Windows に問い合わせ、その形に青い枠を出す。**枠を合わせる作業が要らない。**

| 操作 | 動作 |
|---|---|
| マウスを動かす | その下のウィンドウ（や、その中の部品）に枠が吸い付く |
| **クリック**（動かさずに離す） | 青い枠の範囲を撮る |
| **マウスホイール** | 部品 → もっと大きい部品 → ウィンドウ全体、と範囲を広げる／狭める |
| ドラッグ | 吸い付きを無視して自由に選ぶ（今まで通り） |

取れるのは**位置と大きさだけ**で、ウィンドウのタイトルや中身は読まない。

ウィンドウ**全体**はどのアプリでも取れる。「メニューバーだけ」のような**中の部品**は、
昔ながらの作りのアプリ（PowerShell、エクスプローラー、メモ帳など）なら取れるが、
新しい作りのアプリ（Chrome、VSCode、Electron 製など）は中身を1枚の絵として描いているので取れない。

**このアプリ自身のウィンドウ（編集画面・履歴パネル・浮かせた絵）には吸い付かない。** 撮影用の暗幕を
誤って掴まないようにするため、自分のウィンドウは一覧から外している。ドラッグでなら選べる。

切りたいときは、設定画面の「カーソルの下のウィンドウに枠を吸い付かせる」を外す。

## 前回と同じ範囲でもう一度撮る

直前に範囲選択で撮ったのと**1ピクセルも違わない範囲**を、暗幕を出さずにすぐ撮る。
「直してもらう → 同じ所を撮って見せる」の往復や、前後を並べて比べたいときに使う。
撮ったあとは、ふつうの撮影と同じく保存先に入り、履歴に並び、編集画面が開く。

| 入口 | 動作 |
|---|---|
| トレイの右クリック →「前回と同じ範囲で撮る」 | 前回の範囲をすぐ撮る |
| 設定の「同じ範囲でもう一度」に決めたキー | 同上（**既定はキー無し**。他のアプリとぶつからないキーを自分で決める） |
| 履歴パネルの下の「同じ範囲」 | 同上。パネルは写り込まないよう先に引っ込む |
| 編集画面の「同じ範囲で撮り直す」 | **いま開いている絵と同じ範囲**を撮り直し、新しい1枚として開く。元の絵と書き込みはそのまま残り、新しい絵には書き込みを引き継がない。撮る間は編集画面と履歴パネルが一瞬隠れる |
| トレイの右クリック →「前回と同じ範囲で録画」 | 前回の範囲で、すぐ録画を始める（録画中・撮影中は動かない） |

- 覚えるのは**範囲選択（ドラッグ・窓への吸い付き・Space）と録画で選んだ範囲**。画面全体・スクロール撮影の範囲は覚えない
- 編集画面の「同じ範囲で撮り直す」は、範囲選択で撮った絵にだけ出る
- まだ一度も範囲で撮っていないとき、またはモニタの抜き差し・拡大率の変更などで画面の構成が変わったときは、
  **当てずっぽうで撮らずに、ふつうの範囲選択の画面になる**。トレイの項目名にも「（範囲を選ぶ）」と出る

## 長いページを1枚に（スクロールキャプチャ）

トレイアイコンを右クリック →「**スクロールして長いページを撮る**」。
青い案内が出たら、**スクロールする中身（ページ本体）**の上に範囲を取る。窓に吸い付くので、
ブラウザの本文あたりでクリックするだけでよい。

そのあとは自動で進む。ホイールを送って少しずつスクロールし、そのたびに撮って、
前の絵との重なりを見つけて縦につないでいく。終わると1枚の長い画像として編集画面が開く。

- 進み具合は画面の隅に出る。**Esc** か「中止」でそこまでの分をつなぐ
- 一番下まで来たら自動で止まる。縦 20000px でも止まる
- 範囲は**縦 160px 以上**が必要（重なりを見つけるため）

**うまくいかないとき**

| 症状 | 理由と対処 |
|---|---|
| 1枚しか撮れない | 選んだ場所がスクロールしなかった。ページ本体の上に取り直す |
| 途中で止まる | 継ぎ目が分からなくなった。固定ヘッダーや動く広告があると起きやすい。範囲を狭めると通ることがある |
| ヘッダーが何度も写る | 画面に貼り付いたまま動かない部分は、その回数ぶん写り込む（仕組み上避けられない） |

**撮影中はマウスに触らない。** ホイールは「カーソルの下にある窓」に届くので、途中でマウスを動かすと
別の窓に飛んでしまう。

うまくいかなかったときは、出てくるお知らせのボタンで原因を確かめられる。

- **詳しい記録を開く** — 1回ごとに何ピクセル動いたか・どこで止まったか（`%APPDATA%\スクショ\scroll-log.txt`）
- **比べた2枚を見る** — 実際に見比べた2枚の絵（`%APPDATA%\スクショ\scroll-debug\`）。
  2枚目がスクロールした絵になっていなければ、ホイールがそのページに届いていない

Windows の「**非アクティブ ウィンドウをスクロールする**」（設定 → Bluetooth とデバイス → マウス）が
オフだと、手前のウィンドウしかスクロールできない。既定はオンなのでふつうは気にしなくてよい。

## 時間差で撮る

トレイアイコンを右クリック →「**時間差で撮る**」→ 3秒後 / 5秒後 / 10秒後。
マウスを乗せたときだけ出るメニューやツールチップは、撮影キーを押すと消えてしまうので、
先にこれを押しておき、その間にメニューを開いておく。残り秒数はトレイアイコンにマウスを乗せると出る。

## 録画する（GIF・動画）

トレイアイコンを右クリック →「**録画する（GIF・動画）**」。設定でショートカットキーも割り当てられる。

1. 範囲を選ぶ（ウィンドウ吸い付きも使える）。**選んだ瞬間から録り始める**
2. 隅に細い操作バーが出て経過時間が進む。**このバーは録画には写らない**ので、範囲に重なっても平気
3. 「**停止**」で止める（Esc、または録画のキーをもう一度押しても止まる）。「やめる」は捨てて閉じる
4. **止めた時点で MP4 と GIF の両方が保存先フォルダに入っている。** 確認画面が**1回だけ手前に出る**
   ので、その場で再生して確かめるだけでよい（そのあと他の窓を触れば後ろに回るが、タスクバーの
   アイコンから戻せる）。別の名前にしたいときだけ「動画に名前を付ける」「GIFに名前を付ける」を押す

- 録ったものは**撮影履歴にも並ぶ**（サムネイルに再生マークと長さが出る）。**ダブルクリックで再生**
- **パソコンで鳴っている音も一緒に入る**（マイクではなく、スピーカーから出ている音）。
  設定で切れる。長さの上限は 10 分
- 動画は **MP4（H.264）**なので、Windows のプレイヤーや PowerPoint でそのまま開ける
- GIF は色が 256 色までなので、動画よりファイルが大きくなることがある。重いときは設定で
  「GIF のなめらかさ」を下げる。**横幅は既定で縮めない**（縮めると文字がぼやけるため）
- 写真やグラデーションの多い画面は、256 色に収める都合で**細かい網目**が入る。
  これは色の段差（縞）を目立たなくするためのもので、離れて見ると元の色に近く見える
- 256 色に減らす都合で、肌の色などは**ほんの少し薄く**なる。動画のほうは元のままなので、
  色が大事なときは動画で保存する

## あとから直す（履歴パネル）

**赤枠や矢印は画像に焼き付けません。**「どこに・何色で・どの太さで」という形で別に覚えていて、
絵のほうは保存先フォルダのファイルをそのまま読み直します。だから**何日たっても選び直して動かせる**のに、
同じ絵が2箇所にできません。

- **開くのはトレイアイコンを左クリックしたときだけです。** 撮った直後には出ません
- 出ているあいだに**もう一度トレイアイコンを左クリックすると、その場ですぐ閉じます**
  （編集画面が開くので、二重に出てくると邪魔になるため）
- 出したパネルは**マウスが離れて2秒でふわっと引っ込みます**
  （消えかけている間にマウスを戻せば、そのまま元に戻ります）。
  **開いてから一度もマウスを乗せなかったときは、5秒待って引っ込みます**
- **古いものが左上、いちばん新しいものが右下（最後）に並びます**（Screenpresso と同じ）。
  新しく撮ったときとパネルを出したときは、最新が見える一番下まで自動で送ります
- **既定で3列×3段の9枚が見えます。** 端をドラッグすれば大きさを変えられ、その形を覚えます
- サムネイルの大きさは設定画面のつまみで **64〜240px** の間で変えられます（大きくすると列が減ります）
- **ダブルクリック**でその1枚を編集画面に開き直します。前に描いた枠も矢印もそのまま掴めます。
  開いた編集画面が手前に出て、パネルはその後ろに回ります（パネルをクリックすればまた手前に戻ります）
- **選んで Ctrl+C** で、開かずにそのままクリップボードへコピーできます。書き込みと切り抜き、いま選んでいる仕上げも入った、
  **編集画面で Ctrl+C したときと同じ絵**です（書き込みや仕上げがある絵は、作るのに一瞬かかります）。
  コピーしたら下に「コピーしました」と出ます。何枚も選んでいるときと録画はコピーしません（ドラッグで渡します）
- **何枚でもまとめて選べます**（エクスプローラーと同じ操作です）

  | 操作 | えらび方 |
  |---|---|
  | クリック | その1枚だけ |
  | **Ctrl+クリック** | 1枚ずつ足す・外す（離れたものも選べます） |
  | **Shift+クリック** | 前に押したものから、そこまでを一気に |
  | **Ctrl+A** | 一覧のぜんぶ |
  | **Esc** ／ 一覧の空いている所をクリック | 解除 |

  2枚以上えらぶと、右上に**「◯件えらび中」**と出ます
- **外へドラッグすると、保存先にある原寸のファイルがそのまま渡ります**（一覧に見えている小さい絵では
  ありません）。書き込み済みなら `_書き込み.png`、録画は動画と GIF の両方が渡ります。
  **何枚か選んでいれば、その全部が1回のドラッグでまとめて渡ります**（選んである中の1枚を掴んで引っぱる）。
  渡る順番は、クリックした順ではなく**一覧に並んでいる順**です
- **ピン留めボタン**を押すと出しっぱなしになります（次に起動したときも出ます）
- **下のボタン列**から、パネルを開いたまま次のことができます：撮る／同じ範囲（前回と同じ範囲で撮る）／長いページ（スクロール撮影）／録画／
  **編集**（選んだ1枚を開く。録画を選ぶと「再生」に変わります）／フォルダ／設定、そして右端の**大きい「×」で閉じる**。
  撮影系を押すと、パネル自身が写り込まないよう自動で引っ込みます。
  **「編集」が押せるのは1つだけ選んでいるときです**（何枚も選んだまま押して、編集画面がいくつも開かないようにするため）
- **右クリック**でメニュー：編集する／クリップボードにコピー／画面に浮かせる／ファイルの場所を開く／履歴から消す。
  何枚か選んでいるときは**まとめて扱う**メニューに変わります（◯枚を画面に浮かせる／横に並べて1枚に／縦に並べて1枚に／違いに赤枠を付ける／ファイルの場所を開く／◯件を履歴から消す）
- **何枚かを並べて1枚に**：2枚以上選んで右クリック →「**横に並べて1枚に**」か「**縦に並べて1枚に**」。
  ビフォー・アフターや手順のまとめ図が1枚で作れます
  - 並ぶ順は**一覧の並び順（古いものが先＝左・上）**です
  - 各絵の上に見出しが自動で付きます。**2枚なら「前」「後」、3枚以上なら①②③…**。
    見出しは普通の文字なので、編集画面でダブルクリックすれば書き直せます（消すのも自由）
  - 書き込みと切り抜きは**そのままの見た目で**並びます。大きさの違う絵は縮めずに原寸のまま並べ、
    足りない所は白い余白になります（縮めると字がにじむため）
  - できた絵は**新しい1枚として保存先に保存され、履歴に入り、編集画面で開きます**。元の絵はそのままです。
    ただし元の絵の書き込みは並べた絵に描き込み済みなので、あとで元の絵の矢印を直しても、並べた絵には反映されません
  - 録画は並べられません（選んでいても除いて並べ、下にその旨が出ます）。書き込み入りの絵が多いと、作るのに少し時間がかかります
  - 縦に長くなったら、編集画面の「分割保存」で Google ドキュメントにそのまま貼れます
- **2枚の違いに自動で赤枠**：2枚選んで右クリック →「**違いに赤枠を付ける（同じ範囲で撮った2枚）**」。
  直してもらう前と後で「どこが変わったか」を一目で見せられます
  - **新しいほう（あとで撮ったほう）が編集画面で開き**、古いほうから変わった所に赤い四角（太さ 4px）が自動で置かれます。
    置いたら「◯か所に枠を付けました」、違いが無ければ「違いは見つかりませんでした」と出て何も置きません
  - 四角は**ふつうの四角**なので、消す・動かす・色や太さを変えるが自由です。**Ctrl+Z 1回でまとめて消せます**。元の絵は変わりません
  - 比べられるのは**同じ大きさの2枚だけ**です（「前回と同じ範囲で撮る」で撮った2枚がいちばん確実）。
    大きさが違う・録画が入っている・2枚ではないときは、押すと「同じ範囲で撮った同じ大きさの2枚を選んでください」と出ます。
    スクロール位置がずれた2枚は、中身が同じでも全部違う扱いになります
  - 比べるのは**書き込む前の元の絵どうし**です（前に描いた矢印などは違いに数えません）
  - 文字のにじみや小さな色の揺れ、点滅するカーソル（大きな文字の入力欄の縦に長いカーソルも）は無視します。近い違いは1つの枠にまとめ、
    枠が30を超えそうなときはさらに大きくまとめます
  - 新しいほうを切り抜いてあるときは、切り抜いた範囲の中だけに枠を付けます
- **「履歴から消す」で消えるのは履歴だけです。** 保存先フォルダのファイルはそのまま残ります
- **録画も同じ場所に並びます。** こちらはダブルクリックで再生できます
- 左クリックのほかに、右クリックの「履歴パネルを開く」、編集画面の「履歴」ボタンからも開けます

書き込みは**押すたびに自動で履歴へ保存**されます。編集画面を閉じるときに「保存しますか？」とは聞きません。

置き場は `%APPDATA%\スクショ\library`。入っているのはサムネイルと書き込みの位置だけなので軽いです。
既定で**300枚**まで残し、超えたら古いものから消えます（設定で変更可）。消えるのは履歴だけで、
**保存先フォルダのファイルは残ります**。逆に、保存先のファイルを自分で消したり動かしたりすると、
その履歴は開けなくなります。

## 画面に浮かせて置いておく

撮った絵を**枠のない小さな窓にして、いつもいちばん手前に浮かべておける。**
直す前の画面を隅に置いたまま見比べる、数字を見ながら別の画面に打ち込む、といった使い方をする。

| 入口 | 動作 |
|---|---|
| 編集画面の下の帯の「**浮かせる**」 | いま見えている絵（書き込み・切り抜き込み）を浮かせる。編集画面はそのまま残る |
| 履歴パネルの右クリック →「**画面に浮かせる**」 | その1枚を浮かせる。何枚か選んでいれば全部（録画は除く） |
| トレイの右クリック →「**浮かせた絵をすべて閉じる**」 | 浮かせている絵を一度に全部閉じる（浮かせているときだけ出る） |

浮かせた絵の操作：

| 操作 | 動作 |
|---|---|
| ドラッグ | 動かす |
| マウスホイール | 大きさを変える（カーソルの下の所を中心に。等倍の4倍まで） |
| 縁・四隅をドラッグ | 大きさを細かく合わせる（縦横の比はそのまま。反対側の辺・角は動かない）。ホイールで大まかに決めてからこちらで微調整する |
| **Ctrl**+マウスホイール | 濃さを変える（20%まで薄くでき、下の画面が透けて見える） |
| ダブルクリック ／ **Esc** | 閉じる |
| 右クリック | 閉じる／編集画面で開く／クリップボードにコピー |

- 大きさは**等倍**（撮ったときと同じ大きさ）。範囲を選んで撮った絵は、**撮った場所にぴったり重なって**出る。
  モニタの抜き差しや拡大率の変更で画面の構成が変わっていたときと、全画面・スクロール撮影・取り込んだ絵は画面の真ん中寄りに出る
- 画面に入りきらない大きな絵は、入る大きさまで縮めて出す
- 仕上げ（影つき・背景つき）は付かない。右クリックのコピーも、浮かべている絵そのもの
- **浮かせた絵は、撮影や録画（ほかの録画ソフトも含む）にそのまま写る。**
  ただし**スクロール撮影のあいだだけは自動で隠れ**、終わると元の場所に戻る（ホイールが浮かせた絵に吸われるため）
- 浮かせた絵を閉じても、保存先のファイルや履歴はそのまま。アプリを終了すると全部閉じる（次に起動しても出てこない）

## ほかの画像を開く（撮ったもの以外）

手元にある JPEG や PNG も、このアプリで開いて書き込める。入り口は2つ。

- **履歴パネルに画像をドラッグして落とす**（すぐ使える）
- **右クリック →「その他のオプションを表示」→「送る」→「スクショで開く」**
  こちらは設定の「ほかの画像を開く」で**先に一度オンにしておく**（オフのあいだは「送る」に出ない）

どちらも、**保存先フォルダ（ピクチャ\スクショ）にコピーしてから**開き、撮影履歴にも並ぶ。
**元のファイルはそのまま残る**（動かさない・消さない）。

- 同じ絵を2回渡しても増えない。前に取り込んだものを開き直す
- 保存先フォルダの中にある絵は、コピーを作らずそのまま開く
- 何枚かまとめて渡したときは、履歴に入れるだけで編集画面は開かない（ウィンドウが何枚も開かないようにするため）
- 扱えるのは .png / .jpg / .jpeg / .gif / .bmp / .webp。中身が読めないものは取り込まない
- JPEG に書き込んだときも、書き出されるのは PNG（`_書き込み.png`）。元の JPEG は無傷のまま

Windows の「プログラムから開く」の一覧には出ない。あそこに出すにはレジストリへの登録が必要で、
このアプリは exe を作らない方針のため、ショートカット1個で済む「送る」を使っている。

## 書き込む（編集画面）

上のバーから道具を選び、画像の上をドラッグする。**描いたものは後から動かせる**（消えない図形として持っている）。

| 道具 | キー | 内容 |
|---|---|---|
| 選択 | V | 描いたものを選んで、動かす・大きさを変える（他の道具のままでも掴めるので、切り替えなくてよい） |
| つかむ | H | 拡大して絵がはみ出したとき、ドラッグで見る場所を動かす（Google マップと同じ）。**拡大してスクロールバーが出ると自動でこれに切り替わり**、「全体」などで収まると元の道具に戻る。はみ出していないときはグレーで押せない |
| 四角 | R | 赤枠。枠線の近くをクリックすると掴める |
| 丸 | E | 丸い枠（楕円）。使い方は四角と同じで、Shift を押しながらで正円。輪の近くをクリックすると掴める |
| 矢印 | A | 矢じり付きの線 |
| 直線 | L | 矢じりの無い線 |
| 鉛筆 | P | マウスでなぞったとおりに自由に描く（ペイントのブラシ） |
| 蛍光ペン | M | 半透明の太い線で、文字の上をなぞって目立たせる。**Shift を押しながらで真横にまっすぐ引ける**（ログの1行をなぞる用）。矢印や文字より必ず下に描かれる。明るい地では下の文字がくっきり残る塗り方、暗い地ではふつうの半透明になる（描いた時点で下の明るさを見て決まる）。蛍光ペンを持っているあいだは、置いた蛍光ペンの上からでも続けて引ける（動かすときは「選択」に持ち替える） |
| 番号 | N | 連番マーカー ①②③。クリックで置くだけ。ドラッグすると大きさを決められる |
| 文字 | T | **ドラッグで入力する枠を取る**と白い欄が開き、枠の幅で自動で改行される（あふれた行は欄の中で矢印キー・ホイールで見られる）。クリックだけなら枠なしで、改行した所でだけ折れる。Ctrl+Enter か、外をクリックで確定。**置いた文字を直すのはダブルクリック**。枠のある文字は選ぶとハンドルで幅を変えられる |
| ぼかし | B | 隠したい部分をモザイクにする。太さでモザイクの粗さが変わる |
| スポットライト | S | 見てほしい所を四角と同じ操作で囲むと、**それ以外が半分くらい暗くなる**。何か所でも置け、重なっても二重には暗くならない。暗さは決まっているので太さの欄は出ない。枠線は描かれないので、選んでいるときとスポットライトを持っているときだけ点線で範囲が見える。明るい所と暗い所の境目の近くをクリックすると掴める |
| 拡大鏡 | Z | 読ませたい所を囲むと、そこを**約2倍に拡大した丸いのぞき窓**が横に出て、元の枠と線でつながる。**丸はドラッグで好きな所へ動かせ**、丸の右下の四角をドラッグすると大きさ（＝倍率）が変わる。元の枠も動かせ、そのぶん映る場所が変わる。ぼかした所はのぞき窓の中でもぼけたまま。丸を画像の外へ出すと画角が広がる |
| 切り抜き | C | ドラッグした範囲だけを残す（Ctrl+Z で戻せる） |

| キー | 動作 |
|---|---|
| **Ctrl+C** | 絵をクリップボードにコピー（そのまま貼り付けられる）。**何かを選んでいるときは、その図形のコピー**になる |
| **Ctrl+V** | コピーした図形を貼り付ける。少しずらして置かれ、続けて押すとさらにずれる |
| **Ctrl+S** | 書き込み（または仕上げ）があれば `_書き込み.png` を書き出して、**そのまま編集ウィンドウを閉じる**。どちらも無いときは既に保存済みなので閉じるだけ |
| **Ctrl+Alt+S** | 名前を付けて保存。書き込みも仕上げも無いときは**元のファイルの名前が変わる**（増えない） |
| 分割保存ボタン | 縦長のときだけ出る。何枚かに切り分けて連番で保存（下の節を参照） |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Delete | 選んでいるものを消す |
| 右クリック | カーソルの下にあるものを消す |
| 矢印キー | 選んでいるものを1px動かす（Shift で10px） |
| Shift を押しながら描く | 正方形・正円・水平垂直・45度にそろえる。蛍光ペンは真横 |
| Shift を押しながら動かす | ほかの図形（と絵）の**中心・端**、縦や横に並んだ2つと**同じ間隔**になる位置へ吸い付く。吸い付いた線がピンクで出る。連番は Shift+クリックで置いても吸い付く（縦に ①②③ をきれいに並べる用） |
| Ctrl+マウスホイール | 拡大・縮小 |
| **1〜4** | 書き方のお気に入りに持ち替える（下の節を参照）。文字を入力している最中は効かない |
| **F** | 集中モード（枠も道具も消して絵だけにする）を切り替える |
| Esc | 選択を解除。集中モード中なら解除。どちらでもなければウィンドウを閉じる |

**一度置いたものは、どの道具を持っていても1回のクリックで掴める。** 動かす・大きさを変えるために
「選択」へ切り替え直す必要はない。**文字の中身を直したいときだけダブルクリック**する。

- カーソルを乗せると形が変わるので、そこが掴めるかどうかはそれで分かる
- 四角・丸は**枠線の近く**が掴む場所。内側は空いている扱いなので、中に別のものを描ける
- 蛍光ペンはほかの図形より下にあるので、重なっているときは上に見えているほうが先に掴まれる
- 重なる順は下から「絵 → ぼかし → スポットライトの暗さ → 拡大鏡 → 蛍光ペン → 矢印・文字など」。
  蛍光ペン・矢印・文字は暗くした所の上でも明るいまま乗る（蛍光ペンの線の所だけは暗くならない）
- 拡大鏡は、丸の上を押すと丸だけ、元の枠線の近くを押すと枠だけが動く。矢印キーと貼り付けでは両方まとめて動く
- すでに置いたものの上に重ねて描きたいときは、少しずらして描いてから動かす
- 切り抜きだけは別で、置いたものの上からでもそのまま範囲を取れる

色と太さは、**選んでいる図形があればその図形にも反映**される。最後に使った色・太さ・文字の大きさ・文字の飾りは次に撮ったときも引き継がれる。
太さは 2 / 4 / 7 / 12 / 20px の5段階。ぼかしはこの太さでモザイクの粗さが変わる。
蛍光ペンだけは文字の高さに届くよう、専用の 12 / 18 / 24 / 32 / 44px の5段階になる（蛍光ペンを持つか選ぶと入れ替わる）。
色も蛍光ペンだけ別に覚えていて、最初は黄色。蛍光ペンを持つか選んでいるときに色を選ぶと、蛍光ペンの色だけが変わる。
文字・連番マーカーを持っている（選んでいる）ときは太さの欄は出ず、文字の大きさの欄に入れ替わる。

### 文字の大きさと飾り

文字ツール（または文字を選んだとき）だけ、ツールバーにプルダウンが出る。

- **大きさ** — **9px から 96px まで16段階**（9 / 12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 / 36 / 40 / 48 / 56 / 64 / 80 / 96）。
  連番マーカー ①②③ の丸の大きさもこれで決まる
- **飾り** — 背景に負けて読めなくならないための縁取りと影。文字ごとに変えられる
- **フチの太さ** — 細い / ふつう / 太い / 極太 / ベタ塗りの5段階。フチが出る飾りを選んでいるときだけ出る。
  **「ベタ塗り」にすると文字のまわりが埋まって、白い板に載せたような見た目**になる。
  太さは文字の大きさに対する比なので、字を大きくすればフチも一緒に太くなる

| 飾り | どうなるか |
|---|---|
| **おまかせ**（既定） | 文字の色を見て、明るい色なら黒フチ、暗い色なら白フチを自動で付ける |
| 白フチ / 黒フチ | 背景の明るさに関わらず、フチの色を自分で決める |
| 影 | フチは付けず、右下に影を落とす |
| 白フチ＋影 | 白フチの外側に影。**写真や複雑な画面の上でいちばん強い** |
| 飾りなし | 文字だけ。すっきりした画面に大きな字を置くとき |

### 書き方のお気に入り（いつもの書き方をワンクリックで）

下の帯の右寄りに「お気に入り」のボタンが4つある。ボタンの絵は**道具の形を、その色で**描いたもの。

- **押す（またはキー 1〜4）** と、その道具に持ち替えて、色・太さ・文字の大きさ・飾り・フチの太さが一度に切り替わる。
  図形を選んでいるときは、その図形にも同じ書き方が付く（文字なら色・大きさ・飾り、矢印や四角なら色・太さ）
- **Ctrl+クリック** で、いまの書き方をそのボタンに登録し直す。図形を選んでいればその図形の書き方、
  選んでいなければ持っている道具と今の設定が入る（選択・つかむ・切り抜きを持っているときは登録できない）
- ボタンにカーソルを乗せると、中身（例：`青・文字 48px・白フチ（フチ 極太）`）が出る
- いまの道具と書き方がお気に入りと同じときは、そのボタンが青く縁取られる
- 登録した中身は次に撮ったときも残る。最初は「青の大きい白フチ文字」「赤の大きい白フチ文字」「赤の四角」「赤の矢印」

### はみ出した文字のぶんだけ画角が広がる

**画像の外に文字などを置いても切れない。** はみ出したぶんは自動で画角に足されるので、
そのまま保存・コピーすれば全部入る。

- 増えた部分は**透明**。編集画面ではチェック柄で見え、PNG で保存すれば透けたまま出る。
  切り抜いたあとに画角が広がっても、切り抜いて捨てた絵（ぼかし・スポットライトの暗さも）は出てこない
- 拡大鏡の丸は、自動で置くときは影まで含めて絵の中に収まる所を選ぶので、それだけで画角が広がることはない
  （狭い範囲では丸を少し小さくして収める。7割まで縮めても収まらないほど狭いときや、自分で外へ動かしたときは広がる）
- 左下のサイズ表示が `741 × 382 px（はみ出したぶんを足しています）` に変わる。
  この数字が実際に保存される大きさ
- 文字を画像の中に戻せば、画角も元に戻る。描いている最中は動かず、離したときに広がる
- **切り抜きをすると、その外に丸ごと出ている書き込みは消える**（残すと画角がまた広がって切り抜けないため）。
  消えて困るときは Ctrl+Z で戻せる

### 集中モード（絵だけにして、貼ったときの見え方を見る）

ツールバーの **「集中」ボタン（キー F）** で切り替える。ウィンドウの枠（タイトルバー）も道具も消えて、
**画面には絵だけ**が残る。どこかのページに貼ったらどう見えるかを、まわりの枠に邪魔されずに確かめるためのもの。

- **カーソルをウィンドウの中に入れている間だけ道具が出る**（絵の上に半透明で重なる）。外へ出すとまた消える
- ウィンドウの形は絵の縦横比ちょうどに固定される。大きさを変えても絵はウィンドウいっぱいのまま。
  ただし**原寸より大きくは引き伸ばさない**ので、原寸より広げると周りに余白が出る
- 枠が無いので、**動かすときは道具が出ている間に、ツールバーの空いている所をドラッグ**する
- 集中モード中も、いつも通り書き込み・切り抜きができる。切り抜くとウィンドウの形もその比に変わる
- 戻すのは同じボタン（「集中を解除」）か **Esc**、またはもう一度 **F**

切り替えるときは中身を引き継いでウィンドウを作り直している（Windows は開いたあとのウィンドウから
枠だけを外せないため）。描いたもの・切り抜き・保存先・仕上げはそのまま残るが、**「元に戻す」の履歴だけは
切り替えで消える**。

### 個人情報・APIキーを自動でぼかす

**撮った直後に、裏で写っている文字を読んで、見られて困りそうな所にぼかしを置く。**
編集画面はすぐ開き、読んでいる間も書き込める（下の帯の「自動ぼかし」ボタンが「確認中…」になって押せなくなる。ふつうは1秒前後）。

- 探すもの：メールアドレス／電話番号（日本の形）／クレジットカード番号らしい数字の並び／
  APIキー・トークンらしい文字列（`sk-`・`sk-ant-`・`ghp_`・`github_pat_`・`AKIA`・`xoxb-`・`AIza` で始まるもの、
  `API_KEY=…` のような値、長いランダムな英数字）／このパソコンのユーザー名（`C:\Users\<名前>` の名前の部分）／
  設定の「自動でぼかす言葉」に登録した言葉／
  見出しの右（または真下の行）にある値：お名前・氏名・名前・住所・所在地・名義人・有効期限・セキュリティコード・暗証番号・
  パスワード・ユーザー名・ユーザーID・ログインID・会員番号・お客様番号・顧客ID・顧客番号・社員番号・従業員番号・契約番号・
  口座番号・携帯番号・生年月日・マイナンバー・免許証番号・保険証番号・パスポート番号・PIN・CVV など、
  それに設定の「見出しとして探す言葉」に書いた見出し。表のように見出しの列と値の列が離れていても、同じ高さの右にあれば値とみなす
  （「パスワードを忘れた方」のように文の途中に出てきた見出しは対象外）
- **置いたときだけ**、赤枠のお知らせ「◯か所見つけてぼかしました。見落としが必ずあるので、必ず自分の目でも確認してください。」が出る。
  「閉じる」を押すまで消えない。何も見つからなかったときは何も出ない
- 置かれるのは**ふつうのぼかし**。動かす・大きさを変える・右クリックで消すができ、**Ctrl+Z 1回で全部まとめて戻せる**
- 読み取りは語のまとまりごとなので、`API_KEY=sk-…` は行ごとぼかすなど、**少し広めに隠れる**。
  ターミナルで次の行へ折り返した長いキーは、次の行の頭もいっしょにぼかす
- **見落としは必ずある**（小さい字・薄い字・読み間違い・画像の中の文字など）。お知らせが出なくても、貼る前に自分の目で確かめる
- 下の帯の「**自動ぼかし**」を押すと、いつでも読み直せる（履歴から開いた絵・取り込んだ絵・書き込みの途中でも使える）。
  すでにぼかしてある所には重ねない。切り抜いてあれば、その範囲の中だけに置く
- 読み終わる前にコピーしていたときは、お知らせに「もう一度コピーしてください」と出る（先にコピーした絵にはぼかしが入っていない）
- 読み取れなかった・10秒たっても終わらないときは、黙ってやめる（撮影や保存は止まらない）
- 文字の読み取りは Windows に入っている機能を使い、**このパソコンの中だけで行う**。外へは送らず、読んだ文字はどこにも残さない
- やめたいときは設定の「撮影後に個人情報を自動でぼかす」を外す（外しても「自動ぼかし」ボタンは使える）。録画（MP4・GIF）には効かない

### 絵の大きさを変える（サイズ変更）

下の帯の左、サイズ表示の横の **「サイズ」** を押すと、大きさを決めるダイアログが出る。

| 指定 | どうなるか |
|---|---|
| **割合** | 撮ったときの大きさの ◯%。25 / 50 / 67 / 75 / 100 / 200% はボタン1つで入る |
| **幅** | 出来上がりの横幅を px で決める。高さは比に合わせて自動 |
| **高さ** | 出来上がりの高さを px で決める。幅は比に合わせて自動 |

- **縦横の比はいつも保つ**（崩すと文字がゆがむだけなので、比を崩す指定は無い）
- OK を押すと**編集画面の絵がその大きさになる**。描いてあった矢印・文字も同じ割合で小さく（大きく）なる。**Ctrl+Z で戻せる**
- 大きさを変えてあるあいだは、ボタンが青く縁取られて「サイズ 50%」のように倍率が出る。ダイアログの「撮ったときの大きさに戻す」で元どおり
- 前回 OK した値を覚えていて、次にダイアログを開いたとき最初から入っている（新しく撮った絵を勝手に縮めはしない）
- 変えた大きさは履歴にも残り、開き直しても・履歴からコピーしても・浮かせても・並べて1枚にしても、その大きさで出る。保存先の元の絵はそのまま

**画質について**

- 縮めるときは **Lanczos（ランチョス）** という、文字の輪郭がくっきり残る計算を使う（ふつうの縮め方より文字がにじみにくい）
- **何度変えても、毎回撮ったときの絵から作り直す。** 50% → 75% と変えても劣化は積み重ならず、100% に戻せば元の画質のまま
- 矢印・文字などの書き込みは、変えたあとの大きさで描き直すのでにじまない
- 拡大は **200%・300% のような整数倍なら点をそのまま大きくする**のでにじまない。150% のような半端な倍率は少しにじむ
- コピー・保存はすべて PNG（保存しても画質が落ちない形式）。JPEG で出すことは無い
- 元の字が小さい画面を大きく縮めると、字そのものが小さくなって読みにくくなる（これはどの方法でも避けられない）

### 見栄えよく仕上げる（余白・角丸・影・背景）

下の帯の **「仕上げ：◯◯」** のプルダウンで、コピー・保存するときの見た目を選ぶ。
資料や動画のサムネイルに貼るとき、切り取っただけの四角より一段きれいに見える。

| 仕上げ | どうなるか |
|---|---|
| **そのまま**（既定） | 今までどおり。見えている絵をそのまま出す |
| 黒い縁取り | 余白を足さず、絵の外周に黒い線（2px）を引くだけ。白いページに貼っても境目が分かり、白くない所に貼っても白い帯が出ない |
| 影つき | まわりに白い余白を足し、角を丸めて、下に影を落とす |
| 背景つき | 影つきと同じ形で、まわりを落ち着いた青灰色のグラデーションにする |

- 選んでも見え方の画面は出ない（切り替わるだけ）。見たいときだけ、プルダウンの横の「**見る**」を押す（クリックか Esc で閉じる）
- 付くのは**コピー（Ctrl+C）・保存（`_書き込み.png`）・名前を付けて保存・履歴パネルからのコピー**のとき。
  編集画面の絵にも、保存先にある元の絵にも付かない（元の絵はそのまま）
- 仕上げを選んでいると、書き込みが無くても「保存」で `_書き込み.png` が別に出る（元の絵と違う絵になるため）
- **最後に選んだ仕上げを覚えていて、次に撮った絵にも、開き直した絵にも同じものが付く**。やめるときは「そのまま」に戻す
- 余白・丸み・影は絵の大きさに合わせて自動で決まる。影つき・背景つきは透ける所が無いので、貼り先で黒くならない
- 分割保存と、履歴パネルからのドラッグには付かない（ドラッグで渡るのは保存済みの `_書き込み.png` か元の絵）

## 長い画像を Google ドキュメント等に貼る（分割保存）

縦に長い画像をそのまま Google ドキュメントに貼ると、**文字が潰れて読めなくなる。** これは
Google ドキュメント側の制限で、貼った画像の**面積に上限（2,500万ピクセル²）**があり、
さらに長辺を基準に縮めるため、縦長すぎる絵は横方向まで巻き添えで潰れるのが理由。
クリップボード経由でもファイル挿入でも同じように起きる。

そこで、**縦長の画像を開くと編集画面に「分割保存（◯枚）」ボタンが出る**。押すと、1枚ずつが
ふつうの縦横比になるように切り分けて、`スクショ_2026-09-10_014946_1of5.png` のような
連番で保存フォルダに入る。それを順に貼れば、文字がはっきり読める。

例：3482 × 20114 px（7,000万ピクセル²、上限の2.8倍）→ **5枚**（1枚 3482 × 4023 px、1,400万ピクセル²）

分割した絵には仕上げ（縁取り・影つき・背景つき）を付けない。付けると1枚ずつに縁や影が入り、順に貼ったときに継ぎ目が目立つため。

Windows の「フォト」など、ふつうの画像ビューアはこの制限が無いので、そのままで綺麗に見える。

## 保存先（撮った瞬間に保存される）

**撮った瞬間に、保存先フォルダへそのままファイルが出る。** 何もしなくても、Esc で編集画面を
閉じても残る。既定は `%USERPROFILE%\Pictures\スクショ`、ファイル名は
`スクショ_2026-09-09_231530.png` の形（撮った時刻がそのまま名前になる）。
録画も止めた瞬間に、同じ名前で `.mp4` と `.gif` の両方が出る。
設定画面で変更できる。トレイの右クリック →「保存フォルダを開く」ですぐ開ける。

**同じ絵を2箇所に置かない。** 撮影履歴が持っているのはサムネイルと書き込みの位置だけで、
原寸の絵はこのフォルダの1個しかない。

| したこと | 出るファイル |
|---|---|
| 撮って Esc で閉じる | 1個（`スクショ_日付_時刻.png`） |
| 撮って書き込んだが保存を押さない | 1個のまま。書き込みは履歴に覚えているので次に開けば続きから直せる |
| 書き込んで（または仕上げ・サイズ変更をして）「保存して閉じる」 | 2個（元の絵＋`スクショ_日付_時刻_書き込み.png`）。元の絵を残すので、あとからでも矢印を動かせる |
| 「名前を付けて…」（書き込みも仕上げも無し） | 1個のまま。**コピーではなく名前が変わるだけ** |
| 「名前を付けて…」（書き込みか仕上げあり） | 元の絵＋その名前のファイル |

同じ秒に2枚撮った・同じ名前があったときは、後ろに `-2` が付く（既にあるファイルは上書きしない）。

## 設定

トレイアイコンを右クリック →「設定…」。

- **ショートカットキー** — 範囲・同じ範囲でもう一度・画面全体・スクロール・録画の5つ。欄をクリックしてから、割り当てたいキーを押す。
  修飾キー無しで使えるのはファンクションキーと PrintScreen だけ。
  **決めたキーはトレイの右クリックメニューに並びます**（まだ決めていないものは「［キー未設定］」と出る）
- **保存先フォルダ**
- **撮り方** — カーソルの下のウィンドウに枠を吸い付かせるか
- **自動ぼかし** — 撮影後に個人情報を自動でぼかすか（既定はオン）／**ぼかしの強さ**（弱・標準・強。何が隠れるかは画面に例つきで出る）／
  **自動でぼかす言葉**（1行に1つ。自分の名前・会社名など。`/PA\d{9}/` のように `/` で囲むと「PA＋数字ちょうど9桁」のような形で探す。前後に英数字が続くもの＝10桁などには当たらない）／
  **見出しとして探す言葉**（1行に1つ。社員番号・紹介コードなど、画面の項目名。その右か下の値をぼかす。ぼかしの強さが「弱」でも効く）
- **録画** — 動画のなめらかさ／GIF のなめらかさ／**パソコンの音も録るか**／GIF の横幅の上限
- **履歴パネル** — **サムネイルの大きさ**／何枚まで残すか
- **ほかの画像を開く** — 右クリックの「送る」に「スクショで開く」を出すか

自動起動の設定はここには無い（上の「自動で常駐させる」を参照）。

他のアプリが同じキーを使っていると登録に失敗し、その場で赤い注意書きが出る。

## どのファイルを直すと何が変わるか

| ファイル | 担当 |
|---|---|
| `main.js` | 常駐・トレイ・ホットキー・画面の取り込み・保存・履歴の出し入れ |
| `lib/store.js` | 履歴フォルダの読み書きと削除 |
| `lib/snap.js` | ウィンドウ位置（物理ピクセル）→ オーバーレイ（CSS ピクセル）の換算 |
| `lib/stitch.js` | スクロール撮影のつなぎ合わせ（重なりの検出と連結） |
| `lib/gif.js` | GIF の組み立て（減色・圧縮・差分のコマ） |
| `lib/diff.js` | 2枚の違いを探して、枠にする四角を決める（履歴の「違いに赤枠を付ける」） |
| `lib/pii.js` | 読み取った文字から、個人情報・APIキーらしい所の四角を決める（自動ぼかし） |
| `renderer/record.*` | 録画の操作バーと、止めたあとの確認・保存画面 |
| `renderer/progress.*` | 実行中に隅に出る小さい窓 |
| `renderer/pin.*` | 画面に浮かせた絵の窓（移動・大きさ・濃さは `main.js` の `openPin` まわり） |
| `tools/win-rects.ps1` | Windows にウィンドウ位置を聞く／マウスホイールを送る |
| `tools/ocr.ps1` | Windows の文字読み取りで、絵に写っている文字と位置を読む（自動ぼかし） |
| `renderer/overlay.*` | 範囲選択の画面（暗幕・拡大鏡・サイズ表示） |
| `renderer/editor.*` | 編集画面（道具・描画・元に戻す・書き出し・履歴への自動保存・サイズ変更のダイアログ） |
| `renderer/resample.js` | 絵の大きさを変える計算（Lanczos。整数倍の拡大は点をそのまま拡大） |
| `renderer/library.*` | 右下の履歴パネル |
| `renderer/settings.*` | 設定画面 |
| `preload.js` | 画面と本体のあいだで許可する用件の一覧 |
| `tools/make-icons.js` | アイコンの生成（`npm run icons`） |

直したら、**トレイの「終了」でいったん終わらせてから起動し直す**（起動中のプロセスには反映されない）。
