## 直す前と直した後を、1枚で見せる

Claude などに直してもらったとき、「前はこう → 今はこう」を1枚の絵で伝える手順です。

### 1. 直す前の画面を撮る

**Ctrl+Shift+S** を押して、見せたい所をドラッグで囲みます。

撮った瞬間に保存されるので、開いた編集画面は **Esc** で閉じてかまいません。

### 2. 直ったら「同じ範囲」でもう一度撮る

画面右下のトレイにある赤いアイコンを**左クリック**して履歴パネルを出し、下の **「同じ範囲」** を押します。

<img src="images/01-library-repeat.png" width="480" alt="履歴パネルの下の「同じ範囲」ボタン">

- 範囲を選び直さなくても、**1ピクセルもずれずに**同じ所が撮れます
- トレイのアイコンを右クリック →「前回と同じ範囲で撮る」でも同じです

### 3. 履歴パネルで2枚をえらぶ

直す前の絵を**クリック** → 直した後の絵を **Ctrl を押しながらクリック**。

右上に **「2件えらび中」** と出れば OK です。

<img src="images/anim-select.gif" width="640" alt="直す前の絵をクリックし、直した後の絵を Ctrl+クリックして2枚を選ぶ動き">

### 4. 右クリックして、見せ方を選ぶ

えらんだ絵の上で**右クリック**すると、メニューが出ます。見せ方は2通りあります。

#### A. 「横に並べて1枚に」 — 前と後を並べる

<img src="images/anim-combine.gif" width="640" alt="右クリックして「横に並べて1枚に」を押すと、並べた絵が履歴に加わる動き">

2枚が左右に並んだ1枚ができ、**「前」「後」の見出しが自動で**付きます。できあがりは編集画面で開きます。

<img src="images/03-combined.png" alt="「前」「後」の見出し付きで2枚が横に並んだ編集画面">

- そのまま **Ctrl+C** でコピーして、チャットや資料に貼り付けます
- 見出しはふつうの文字なので、ダブルクリックで書き直せます
- 縦に並べたいときは「縦に並べて1枚に」を選びます

#### B. 「違いに赤枠を付ける」 — 変わった所に印を付ける

<img src="images/anim-diff.gif" width="640" alt="右クリックして「違いに赤枠を付ける」を押す動き">

直した後の絵が編集画面で開き、**変わった所に赤い四角が自動で**付きます。

<img src="images/04-diff.png" alt="変わった2か所に赤枠が付いた編集画面">

- 赤い四角はふつうの四角です。消す・動かす・色を変える、が自由にできます
- **Ctrl+Z を1回**押すと、付いた枠をまとめて消せます

### うまくいかないとき

| こうなった | こうする |
|---|---|
| 「同じ範囲で撮った同じ大きさの2枚を選んでください」と出る | 2枚の大きさが違います。手順2の「同じ範囲」で撮り直します |
| 変わっていない所にも枠が付く | ページのスクロール位置がずれています。同じ位置まで戻してから撮り直します |
| 「同じ範囲」を押すと、範囲を選ぶ画面になる | まだ一度も範囲で撮っていないか、モニタの構成・拡大率が変わっています。そのまま範囲を選べば撮れます |

## 図形をきれいに並べる

同じ四角をいくつも付けて、縦や横にぴったりそろえる手順です。編集画面で使います。

<img src="images/anim-shapes-copy-snap.gif" width="560" alt="四角を選んで Ctrl+C・Ctrl+V で複製し、Shift を押しながらドラッグして下の行にそろえる動き">

### 1. 図形を選んで、Ctrl+C → Ctrl+V

- 付けた四角を**クリック**して選び、**Ctrl+C** → **Ctrl+V**
- 同じ四角が、少しずれた所にできます。続けて Ctrl+V を押すと、さらにずれた所にもう1つできます

### 2. Shift を押しながらドラッグ

- できた四角を掴んで、**Shift を押しながら**動かします
- ほかの図形の**端・中心**にそろう位置に来ると吸い付き、**ピンクの線**が出ます
- 3つ以上あるときは、**間隔が同じ**になる位置にも吸い付きます

**掴む所に気をつける**
- 四角の角と、辺の真ん中にある小さな四角は、大きさを変えるつまみです
- 動かしたいときは、つまみを避けて**辺の上**を掴みます

| ほかの操作 | 動作 |
|---|---|
| 矢印キー | 選んでいる図形を 1px 動かす（Shift を押しながらで 10px） |
| Shift を押しながら描く | 正方形・正円・まっすぐな線になる |
| Ctrl+Z | 1つ前に戻す |

## 見本の絵を浮かせて、見ながら作業する

撮った絵を、いつもいちばん手前に浮かべておく手順です。数字を見ながら別の画面に打ち込むときなどに使います。

### 1. 浮かせる

どちらかで浮かびます。

- 編集画面の下の帯にある **「浮かせる」**
- 履歴パネルで絵を**右クリック** → **「画面に浮かせる」**

**ドラッグ**で好きな所へ動かせます。閉じるときは、**ダブルクリック**か **Esc** です。

### 2. 大きさを変える

**ホイールを回す** — 上へ回すと大きく、下へ回すと小さくなります。カーソルのある所を中心に大きさが変わります。

<img src="images/anim-pin-wheel.gif" width="560" alt="浮かせた絵の上でホイールを回して、大きくしたり小さくしたりする動き">

**四隅をドラッグする** — 細かく合わせたいときに使います。縦と横の比は変わりません。

<img src="images/anim-pin-corner.gif" width="560" alt="浮かせた絵の右下の角をドラッグして大きさを変える動き">

### 3. 透かす

**Ctrl を押しながらホイールを下へ**回すと薄くなり、下の画面が透けて見えます。上へ回すと元の濃さに戻ります。いちばん薄くて 20% までです。

<img src="images/anim-pin-opacity.gif" width="560" alt="Ctrl を押しながらホイールを回して、浮かせた絵を半透明にする動き">

- 浮かせた絵は、撮影や録画にもそのまま写ります
- 浮かせた絵を閉じても、保存したファイルや履歴は消えません

## 個人情報が写った画面を人に渡す

メールアドレスや API キーが写った画面を、ぼかしてから渡す手順です。

### 1. 撮ると、自動でぼける

撮った直後に、写っている文字を読んで、見られて困りそうな所に**自動でぼかしが入ります**。ふつうは1秒ほどです。

- ぼかしが入ったときだけ、赤枠のお知らせが出ます
- 履歴から開いた絵や、あとから書き込んだ絵では、下の帯の **「自動ぼかし」** を押すと読み直します

<img src="images/anim-autoblur.gif" width="560" alt="下の帯の「自動ぼかし」を押すと、メール・電話番号・API キーにぼかしが入り、赤枠のお知らせが出る動き">

見つけるもの：
- メールアドレス
- 電話番号
- カード番号らしい数字
- API キー
- このパソコンのユーザー名
- 設定の「自動でぼかす言葉」に登録した言葉
- パスワード・会員番号などの見出しの横にある値

#### 文字の読み取りは、このパソコンの中だけで完結します

AI サービスやクラウドの読み取りには、画像を送っていません。

- 使っているのは、Windows に最初から入っている文字読み取りの機能 **「Windows.Media.Ocr」**（Windows OCR）です。Windows 10 から標準で入っています
- Microsoft は公式の開発者ブログで、この機能は「インターネット接続なしで、端末の中だけで動く」と説明しています（原文："runs entirely on the device without requiring an Internet connection"）
- 読み取りに使う辞書は、パソコンに入っている日本語・英語の言語データ（Windows の設定の言語オプションにある「光学式文字認識」）です
- このアプリ自体にも、インターネットへ送る処理は入っていません。撮った絵も読んだ文字も外へ出さず、読んだ文字はどこにも残しません
- **自分で確かめる方法**：Wi-Fi を切る（機内モードにする）→ 撮る。ネットにつながっていなくても、自動ぼかしはそのまま効きます
- **調べるときの検索語**：「Windows.Media.Ocr」「Windows OCR オフライン」
- 根拠の資料：[簡単に利用できる PDF 文字認識 OCR 比較まとめ ～ AI OCR の頭抜けた実力](https://recruit.group.gmo/engineer/jisedai/blog/ai-ocr/)（GMO インターネットグループ 次世代システム研究室、2021年）
  - OCR を「ローカル系（パソコンに入れて使う）」と「クラウド型」に分けて比べた記事です。Windows.Media.Ocr は **ローカル系 OCR** として紹介されています
- その他の参考資料：[Optical Character Recognition (OCR) for Windows 10](https://blogs.windows.com/windowsdeveloper/2016/02/08/optical-character-recognition-ocr-for-windows-10/)（Microsoft の Windows Developer Blog・英語。上の原文の出典）

※ Windows 全体の診断データ（Microsoft へ送る利用状況）を送るかどうかは、Windows の設定で決まります。このアプリの読み取りとは別の話です。

#### Presidio（個人情報を見つける Python の道具）は、いまは入れていません

**Presidio（プレシディオ）** は、Microsoft が無料で公開している、文章から個人情報（PII）を見つける道具です。これもパソコンの中だけで動き、人名・地名を文の流れから当てる AI（固有表現抽出）を持っています。組み合わせれば、見出しの無い名前や住所まで拾える見込みがあります。

それでも、**2026年9月時点では導入を見送っています。** 理由は4つです。

- **日本語の名前・住所に弱い**：そのままでは日本語の名前・住所をほとんど見つけられません。日本語用の部品（GiNZA）を足しても、正解率は6割ほどという検証があります（[日本語の個人情報検出はなぜ難しいのか](https://zenn.dev/nexus_api_lab/articles/20260418-japanese-pii-difficulty)）
- **スクショには文の流れが少ない**：画面の文字は、表や項目名の切れ端です。文章向けの AI は、さらに当たりにくくなります
- **いまの仕組みで足りている**：Windows OCR で読んだ文字を、このアプリが日本向けの決まり（電話番号・カード番号・API キーの形、「パスワード」などの見出し、登録した言葉・正規表現）で調べています。Presidio を日本語で使うときにすすめられる構成の大部分を、すでに持っています
- **重く、止まりやすくなる**：Python と数百 MB 以上の部品が増えます。撮ってからぼけるまでが遅くなり、Windows の Smart App Control（知らないプログラムを止める仕組み）に部品が止められることもあります

どちらを使っても、外へは送りません。見送ったのは、手間に見合うほど精度が上がらないためです。

### 2. 足りない所は、自分でぼかす

**自動ぼかしは、見落としが必ずあります。** 貼る前に、自分の目で確かめます。

- 上の例でも、名前と会員番号はぼけていません
- 足りない所は、**B キー**（ツールバーの「ぼかし」）に持ち替えて、ドラッグで囲みます

<img src="images/anim-blur-manual.gif" width="560" alt="B キーでぼかしに持ち替え、名前をドラッグで囲んでぼかす動き">

| こうしたい | こうする |
|---|---|
| 余計な所まで、ぼけた | そのぼかしの上で**右クリック**すると消える |
| 自動のぼかしをまとめて取り消す | **Ctrl+Z を1回** |

### 3. いつも出てくる名前・番号は、登録して自動でぼかす

毎回ぼかす名前や番号は、設定に登録しておくと、次から自動でぼけます。上の例の名前と会員番号も、登録すれば自動ぼかしで消えます。

<img src="images/anim-words.gif" width="640" alt="設定の「自動でぼかす言葉」に「山田花子」と「/A-\d{8}/」を書いて保存し、編集画面で「自動ぼかし」を押すと、名前と会員番号もぼける動き">

1. トレイのアイコンを右クリック →「**設定…**」
2. 「**自動でぼかす言葉**」に、**1行に1つ**ずつ書く（Enter で改行）
3. 「**保存する**」を押す。次に撮った絵から効きます。開いている絵は、下の帯の「自動ぼかし」で読み直します

**名前・会社名は、そのまま書きます。**
- 空白の有無や、全角・半角の違いは気にしなくて大丈夫です。「山田花子」と登録すれば、画面の「山田 花子」（半角の空白）も「山田　花子」（全角の空白）も同じ言葉として探します。英数字の全角・半角（「ＡＢＣ」と「ABC」）も区別しません
- 1行に書いた言葉は、そのひとかたまりで探します。姓だけ・名だけでも隠したいときは、別の行に分けて書きます

**番号のように「形」が決まっているものは、前後を / で囲みます**（正規表現。文字の形で探す書き方）。

| 書き方 | 当たるもの |
|---|---|
| `/A-\d{8}/` | A- のあとに数字8桁（会員番号 A-00123456 など） |
| `/PA\d{9}/` | PA のあとに数字9桁 |
| `/\d{4}-\d{4}/` | 数字4桁・ハイフン・数字4桁 |

- `\d` は数字1文字、`{8}` は「8回」。`\` は **¥** で打っても同じです
- 桁数は**ちょうど**で数えます（`/A-\d{8}/` は、9桁の A-001234567 には当たりません）
- **/ で囲んだ中には、空白を書きません。** 画面の文字は空白を詰めてから探すので、空白入りの式はどこにも当たりません
- 書き間違えて読めない式は、設定画面に赤字で出ます

## 「ここを見て」と目立たせる

見てほしい所を、ひと目で分かるようにする道具です。どれも編集画面で使います。

### スポットライト（S キー）— まわりを暗くする

見てほしい所を囲むと、**それ以外が暗く**なります。いくつでも置けます。

<img src="images/anim-spot.gif" width="560" alt="S キーでスポットライトに持ち替え、ボタンを囲むと、まわりが暗くなる動き">

### 拡大鏡（Z キー）— 小さい字を大きく見せる

読ませたい所を囲むと、**約2倍に拡大した丸いのぞき窓**が横に出ます。

<img src="images/anim-zoom.gif" width="560" alt="Z キーで拡大鏡に持ち替え、小さい字を囲むと、丸く拡大されたのぞき窓が出る動き">

- 丸はドラッグで好きな所へ動かせます
- 丸の右下の小さな四角をドラッグすると、大きさ（倍率）が変わります

### 蛍光ペン（M キー）— 1行をなぞる

文字の上をなぞって目立たせます。**Shift を押しながら**引くと、手がぶれても**横にまっすぐ**引けます。

<img src="images/anim-marker.gif" width="560" alt="M キーで蛍光ペンに持ち替え、Shift を押しながらエラーの1行をなぞる動き">

### いつもの書き方は「お気に入り」に

下の帯の右寄りにある **「お気に入り」の 1〜4** を押す（またはキー **1〜4**）と、登録した道具・色・太さに一度で持ち替えます。

- 最初に入っているもの：1 青の大きい文字／2 赤の大きい文字／3 赤の四角／4 赤の矢印
- 入れ替えたいときは、道具と書き方を決めてから、ボタンを **Ctrl+クリック**

## 長いページを1枚にする

画面に入りきらない長いページを、自動でスクロールしながら撮って、縦長の1枚につなぐ手順です。

<img src="images/anim-scroll.gif" width="560" alt="スクロールする中身をドラッグで囲むと、自動でスクロールしながら撮り、つないだ縦長の1枚が編集画面で開く動き">

### 1. 始める

トレイのアイコンを**右クリック** → **「スクロールして長いページを撮る」**。

### 2. スクロールする中身を囲む

青い案内が出たら、**スクロールする中身（ページの本文）**をドラッグで囲みます。ブラウザなら、本文のあたりをクリックするだけで窓に吸い付きます。

- 縦は **160px 以上**必要です

### 3. 終わるまで待つ

あとは自動です。少しずつスクロールしては撮り、つなぎ目を見つけて縦につないでいきます。

- **終わるまでマウスに触らない**でください。スクロールは「矢印の下にある窓」に届くので、動かすと別の窓がスクロールします
- 一番下まで来ると自動で止まります。途中でやめたいときは **Esc**（そこまでの分をつなぎます）

できあがると、編集画面で開きます。

<img src="images/05-scroll-result.png" alt="つないだ縦長の1枚が開いた編集画面。右上に「分割保存（3枚）」ボタンがある">

**Google ドキュメントなどに貼るとき**
- 縦に長すぎる画像をそのまま貼ると、文字が潰れて読めなくなります
- 上の図のように **「分割保存（◯枚）」** ボタンが出たら、それを押します。ちょうどよい長さに切り分けて保存されるので、順に貼ります

### うまくいかないとき

| こうなった | こうする |
|---|---|
| 1枚しか撮れない | 囲んだ所がスクロールしなかった。ページの本文の上で囲み直す |
| 途中で止まる | つなぎ目が分からなくなった。動く広告や貼り付いた見出しがあると起きやすい。囲む範囲を狭めると通ることがある |
| 見出しが何度も写る | 画面に貼り付いて動かない部分は、スクロールした回数だけ写る（仕組み上さけられない） |

## 操作の様子を動画で見せる

画面の操作を録画して、MP4（動画）と GIF（動く画像）にする手順です。この手順書の動く画像も、ほとんどこの機能で撮っています。

<img src="images/anim-record.gif" width="560" alt="録りたい範囲をドラッグすると録画が始まり、画面の隅の操作バーの「停止」で止める動き">

### 1. 始める

トレイのアイコンを**右クリック** → **「録画する（GIF・動画）」**。

### 2. 録りたい範囲を囲む

ドラッグで囲みます。**放した瞬間から録画が始まります。**

- 画面の隅に、細い**操作バー**が出て、経過時間が進みます
- 操作バーは録画には写らないので、範囲に重なっても平気です
- パソコンで鳴っている音も一緒に録れます（設定で切れます）。長さは 10 分までです

### 3. 「停止」で止める

操作バーの **「停止」**（または **Esc**）で止めます。「やめる」を押すと、録ったものを捨てます。

止めた時点で、**MP4 と GIF の両方が保存先フォルダに入っています。** 画面の真ん中に確認画面が出るので、その場で再生して確かめます。

<img src="images/06-record-confirm.png" width="480" alt="録画の確認画面。録った動画の再生と、動画・GIF の大きさ、名前を付けるボタンが並ぶ">

- 別の名前にしたいときだけ「動画に名前を付ける」「GIFに名前を付ける」を押します
- 録ったものは履歴パネルにも並び、ダブルクリックで再生できます

| こうしたい | こうする |
|---|---|
| GIF が重い | 設定で「GIF のなめらかさ」を下げる |
| 色をきれいに残したい | GIF は 256 色までなので、動画（MP4）のほうを使う |

## 手順に番号を付けて説明する

「ここに入れて、次にここ」と順番を見せたいときは、番号マーカーを使います。編集画面で使います。

<img src="images/anim-steps.gif" width="560" alt="N キーで番号に持ち替え、入力欄の左をクリックして①を置き、Shift を押しながらクリックして②③④を縦にそろえ、1つを右クリックで消すと番号が振り直される動き">

### 1. N キーで持ち替えて、クリックで置く

置いた順に ①②③… と番号が付きます。**大きさは文字の大きさの欄**で決まります（ドラッグして置くと、好きな大きさにできます）。

### 2. Shift を押しながらクリックすると、縦にそろう

少しずれた所をクリックしても、**前の番号の真下（真横）に吸い付いて**、きれいに並びます。

### 3. いらない番号は右クリックで消す

消すと、あとの番号が**自動で詰めて振り直されます**。途中を消しても番号が飛びません。

## 資料に貼る前に、大きさと見た目を整える

### 大きさを変える（サイズ）

下の帯の **「サイズ」** を押すと、大きさを決める画面が出ます。**25〜200% のボタン**か、幅・高さの数字で決めます。

<img src="images/anim-resize.gif" width="640" alt="下の帯の「サイズ」を押し、「50%」を押して OK すると、絵が半分の大きさになる動き">

- 縦横の比はいつも保たれます。描いた矢印や文字も一緒に縮みます
- 何度変えても撮ったときの絵から作り直すので、**画質は落ち重なりません**。Ctrl+Z か「撮ったときの大きさに戻す」で元どおり

### 見栄えよく仕上げる（仕上げ）

下の帯の **「仕上げ：◯◯」** で、コピー・保存するときの見た目を選びます。**「見る」** で、仕上がりを確かめられます（クリックで閉じる）。

<img src="images/anim-finish.gif" width="640" alt="下の帯の「仕上げ」で「背景つき」を選び、「見る」を押すと、まわりに余白と影と背景の付いた仕上がりが出る動き">

| 仕上げ | どうなるか |
|---|---|
| そのまま | 見えている絵をそのまま出す |
| 黒い縁取り | 絵の外周に細い黒線。白いページに貼っても境目が分かる |
| 影つき | まわりに白い余白、角を丸めて影を落とす |
| 背景つき | 影つきと同じ形で、まわりを青灰色のグラデーションに |

- 付くのはコピー・保存のときだけです。保存先にある元の絵はそのまま残ります
- 最後に選んだ仕上げを覚えていて、次に撮った絵にも付きます。やめるときは「そのまま」に戻します

## 貼ったときの見え方を確かめる

**F キー**（またはツールバーの **「集中」**）で、窓の枠も道具も消えて**絵だけ**になります。どこかに貼ったらどう見えるかを、まわりに邪魔されずに確かめられます。

<img src="images/anim-focus.gif" width="640" alt="F キーを押すと枠と道具が消えて絵だけの窓になり、カーソルを乗せると道具が重なって出て、「集中を解除」で元の編集画面に戻る動き">

- **カーソルを乗せている間だけ**、道具が絵の上に出ます。外へ出すと消えます
- そのまま書き込みもできます。動かすときは、道具が出ている間にツールバーの空いた所をドラッグします
- 戻すのは **「集中を解除」**・**Esc**・もう一度 **F** のどれでも。ただし切り替えると「元に戻す」の履歴は消えます
